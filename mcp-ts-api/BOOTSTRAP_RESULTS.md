## 🔒 Security Model

### Deno Sandbox Constraints
- ❌ No filesystem reads/writes
- ❌ No environment variable access
- ❌ No subprocess spawning
- ✅ Network only if `ALLOW_NET` is set
- ✅ Exactly one JSON line output

### Secrets Isolation
- API keys in `.env` (git-ignored)
- Runtime loads and injects to servers
- Model never sees secret values
- Only type signatures visible to model

## 🎯 Architecture Benefits vs Classic MCP

| Metric | Classic MCP | TS API Approach |
|--------|-------------|-----------------|
| Round trips | N (one per tool) | 1 (one program) |
| Context growth | Linear per call | Constant (final output only) |
| Type safety | JSON schema only | Full TypeScript |
| Debugging | Scattered fragments | One program + stdout |
| Tool overload | Increases with tools | Single coherent API |
| Security | Runtime per call | Sandbox once |

## 🐛 Troubleshooting

### Deno Not Found in Smoke Test

**Solution:** Add to PATH in current shell:
```bash
export PATH="$HOME/.deno/bin:$PATH"
npm run smoke
```

Or restart your terminal (Deno added to shell config).

### TypeScript ESM Errors

**Fixed:** Package.json now uses:
```json
"scripts": {
  "gen:bindings": "node --loader ts-node/esm --no-warnings src/generateBindings.ts"
}
```

### Cannot Find OpenAI API Key

Edit `.env`:
```bash
OPENAI_API_KEY=sk-proj-your-actual-key-here
```
