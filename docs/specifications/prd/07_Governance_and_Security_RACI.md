## Security & Privacy
- SUD data segmented; Break‑the‑Glass enforced; all views/edits audited.
- Directory edit permissions limited to Steward/Delegates; read‑only to CRC staff.
- Scoped disclosures in packet generation; HIV/SUD omitted unless policy/consent requires.
